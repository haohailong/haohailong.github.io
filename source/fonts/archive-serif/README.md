# Archive body font

This is a WOFF2 subset of Noto Serif SC from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notoserifsc

The original font is licensed under SIL OFL 1.1; see OFL.txt. The subset retains
all available weight variations and covers every Chinese character present in
the archived HTML, plus Latin text and common punctuation. Size: 626,700 bytes.

The font is served by this site, without a third-party font request. If new
articles or characters are added, regenerate the subset before publishing.
Use scripts/subset_archive_font.py with the original NotoSerifSC[wght].ttf,
a publication directory and the output WOFF2 path; requires fonttools[woff].
